# sc-local-v1

This baseline was authored for Smart Commerce on 2026-10-15. No external corpus was
downloaded or copied; entries are mechanically repeated words/digits, familiar
keyboard sequences and platform-name combinations. The familiar example phrase
is included as a commonly publicized example, not as an imported corpus.

No third-party dataset or license was introduced. The list is original project
material; this provenance record does not change the repository's licensing or
grant a new license on behalf of its owner.

Matching is exact after NFC and Locale.ROOT lowercase, without trimming. Blank
passwords are also rejected. This intentionally small baseline is NOT a complete
breached-password list and provides no coverage guarantee. Review coverage before
public registration is exposed; enlarging it requires provenance/license review.
Password length and this list apply when establishing credentials. Verification
does not apply a newer blocklist to an existing hash, avoiding accidental lockout.
