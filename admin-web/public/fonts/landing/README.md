# Fontes exclusivas da landing

Mona Sans (normal variável 200–900) e Unbounded (normal, faixa utilizada 400–800), subconjunto latin WOFF2. Arquivos obtidos dos recursos públicos de `sistemapacto.com.br/fonts/` em 2026-10-18 para a direção visual autorizada da home. Os URLs de Unbounded 400/800 entregavam os mesmos bytes, consolidados em um único recurso local. As duas famílias são distribuídas sob SIL Open Font License 1.1; licenças originais preservadas nesta pasta.

Projetos e licenças: [Mona Sans](https://github.com/google/fonts/tree/main/ofl/monasans), [Unbounded](https://github.com/google/fonts/tree/main/ofl/unbounded). Fontes sem modificações, hospedadas localmente, sem conexão a provedores durante runtime/build. Nomes CSS `Landing Mona Sans` e `Landing Unbounded` isolam a seleção; a atribuição só ocorre sob `.landing-page`. O restante da plataforma permanece em Arial.
