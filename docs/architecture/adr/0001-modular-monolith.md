# ADR-0001 — Monólito modular
Status: aceito (provisório para MVP)
Contexto: equipe pequena, domínio ainda em validação e necessidade de entrega rápida.
Decisão: Spring Boot monolítico com módulos coesos, banco PostgreSQL e contratos claros.
Consequências: implantação e transações mais simples; disciplina necessária para evitar acoplamento excessivo. Revisar apenas quando métricas justificarem.
