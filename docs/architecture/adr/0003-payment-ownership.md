# ADR-0003 — Titularidade dos pagamentos
Status: aceito como intenção de produto; depende de validação contratual e técnica.
Decisão: cada lojista conecta sua própria conta Mercado Pago; nossa plataforma não centraliza fundos de compradores. Assinatura SaaS é cobrança separada.
Consequências: OAuth e armazenamento seguro de credenciais; validar elegibilidade do modelo de integração, taxas, regras e webhooks antes do código de produção.
